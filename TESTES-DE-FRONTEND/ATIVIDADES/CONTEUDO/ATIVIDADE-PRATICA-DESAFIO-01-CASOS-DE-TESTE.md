## ITEM 1 — Escrever 3 Casos de Teste do Login

**Contexto:** Você, como aluno consultor, foi chamado para escrever os casos de teste do módulo de Login de uma aplicação web antes de ela ser publicada. A tela de login tem os campos E-mail e Senha e o botão Entrar; depois do login certo, o usuário vai para o Painel (Dashboard).

**Comando:** Elabore 3 casos de teste padronizados para o módulo de Login. Para cada caso, especifique: ID, Título, Pré-requisito, Passos numerados (1, 2, 3...) e Resultado Esperado verificável.

**Tópicos:**
- a) Autenticação com credenciais válidas (caminho feliz).
- b) Tentativa de login com senha incorreta (tratamento de erro).
- c) Submissão com o campo de e-mail em branco (validação de formulário no frontend).
